# Simple Calculator

Простой web-калькулятор (MVP). Поддерживает базовые арифметические операции.

## 🚀 Как запустить
Проект не требует сборки (No-Build).
1. Клонируйте репозиторий.
2. Откройте `src/index.html` в любом современном браузере.

## 🛠 Стек технологий
* HTML5 / CSS3
* Vanilla JavaScript (ES6+)

## 🤝 Правила разработки
* Используем [Conventional Commits](https://www.conventionalcommits.org/).
* Ветки именуем в формате `feat/TASK-ID-description`.
